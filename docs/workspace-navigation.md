# 工作区导航与前端状态

右侧从 17 个工具入口收敛为阅读、检索、解读、写作、资料、设置。导航按任务组织，原模块 ID、文献 ID、文件路径及 API 不变。

| 入口 | 内容与边界 |
|---|---|
| 阅读 | 原文与解析视图。返回阅读时隐藏工作区，编辑与检索状态继续存活。 |
| 检索 | 知识库查应用已发布的证据；找论文查外部学术来源并导入。两种查询分别保留自己的输入和结果。 |
| 解读 | 当前论文是共同上下文。粗读梳理论文，图表解释原图原表，图解按知识结构／方法步骤／交互关系选择表达方式。视频拥有自己的来源，切换视频时不显示论文归属提示。 |
| 写作 | Markdown、LaTeX、当前会话产出。已有文件名与编辑状态由各编辑器管理，导航不替它们推断文档身份。 |
| 资料 | 从统一存储清单读取资源及状态，分别显示资源、笔记与成果、处理任务、待核对、回收站。笔记可预览或直接打开对应 Markdown 文档。 |
| 设置 | 常规、知识库、技能与扩展、环境诊断。技能与 MCP 配置不属于文件资料。 |

## 前端分工

- `workspaceNavigation.js` 只定义任务归属与旧布局迁移，不读写业务资源。
- `dock.js` 管理六入口、唯一工作区面板、激活和拖动分栏。点击已打开入口聚焦已有面板；关闭标签才释放面板。
- `taskWorkspace.js` 管理区内视图切换。功能按需挂载一次，切换通过隐藏缓存视图完成，避免重建编辑器、播放器或查询结果。状态提示属于对应视图；隐藏视图的运行提示不会覆盖当前视图。
- 原模块继续负责自己的业务和文档。资料复用 SQLite 生命周期 API；UI 偏好、草稿和布局复用统一 persistence 服务。
- `storageEvents.js` 共享一条存储事件流。侧栏提醒和任务默认列表采用每份资源的最新任务；历史失败不会覆盖后续成功。任务页可勾选历史记录。

## 状态与恢复

工作区、图解表达方式、资料分类和查询条件分别持久化。Markdown 保留文档路径、草稿内容及修订号；LaTeX 保留最近文件和未保存草稿。切换入口与返回阅读均不销毁编辑器；关闭标签或刷新后可恢复草稿。导航不自动保存文档。

资料请求使用序列号丢弃过期响应，防止快速切换分类后旧结果覆盖新页面。知识库检索同样拒绝迟到结果。论文与项目变化通过上下文事件更新资料范围；未选择项目时不能误用“当前项目”筛选。

思维导图使用可解析的 SVG 固有尺寸，在缓存视图隐藏时跳过适应窗口，重新显示后由尺寸观察器调整，避免隐藏面板引发缩放错误。

## 旧布局迁移

原始布局在首次迁移时备份到 `pipaper.workspace.legacy-backup`。按旧活动面板优先保留对应工作区，同一区域的重复工具面板收敛为一个，保留独立区域的分栏尺寸、浮动位置和旧图解表达方式；清除空组。新布局重复迁移应保持一致。迁移恢复期间不发布中间布局。

## 验证

自动测试覆盖活动视图与分栏保留、浮动图解迁移、重复迁移、功能归属、最新任务提醒。浏览器验收覆盖六入口、查询保留、图解切换、视频和图表入口、笔记到编辑器、任务与历史记录、回收站、统一设置、Markdown 未保存草稿在切换／返回阅读／刷新后的恢复。验证过程中不保存原始文档，临时草稿还原到验证前状态。
