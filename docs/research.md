# 研究模块（加法开发第一批）

> 对应《PiPaper_加法开发规划_2026-10-06.md》第一批：A01 项目研究档案、A02 证据卡与文献对比表、A03 假设与研究决策、B1.6 基础导出与恢复。
> 定位：可选增强。不启用研究模块时，文献、阅读、对话、研读、检索、写作与视频照常使用。

## 功能与入口

| 功能 | 入口 | 说明 |
| --- | --- | --- |
| 研究概览（A01） | 侧栏项目栏 🔬 按钮或 dock「研究」 | 为选定项目附加研究档案：问题、范围、阶段目标、约束、成果关联、行动清单与真实时间线 |
| 证据卡（A02.1–A02.2） | 阅读选区弹窗「🔖 保存为证据」；知识检索选区「保存为证据」 | 固定来源：论文带页码，检索带 resourceId/版本/章节/页码；也可在面板手工添加（须填来源说明） |
| 文献对比表（A02.3–A02.6） | 研究面板「文献对比表」 | 自定义列；单元格区分 值/零值/未报告/未核对/不适用，可附来源页码；导出 Markdown 保留这些标记 |
| 想法与假设（A03） | 研究面板「想法与假设」 | 假设草稿、可验证预测、反例与替代解释、支持/反对证据关联；决策（探索中/继续/搁置/修改/停止）自动留历史 |
| 研究方案与基线对齐（A04） | 研究面板「研究方案与基线对齐」 | 验证目标、数据划分、指标定义、预算与停止条件；基线对齐表区分论文设置/仓库配置/实际条件（已对齐/部分/未对齐/不适用）；执行前冻结为带快照的版本，修订不清除历史 |
| 实验台账（A05） | 研究面板「实验台账」 | 逻辑实验下登记运行：成功/失败/中止/不完整四种终态，配置未记录保持空白；指标带来源位置；支持重试/续跑/变体关系；CSV/JSON 导入带预览与列映射，只读文件不执行脚本 |
| 比较与结论（A06） | 研究面板「比较与结论」 | 比较快照固定保存时刻的运行值并记录纳入口径与差异说明；结论卡强制区分观察/探索性/得到支持/负结果，可引用运行、比较、证据、假设、对比表与方案作为依据 |
| 写作引用（A07） | 研究面板「写作引用」 | 登记写作区文件为稿件记录（原文件不动）；从文献库添加引用（自动生成稳定键，冲突拒绝）、复制引用标记、导出 .bib、关联研究结论；引用检查（缺失/重复/失效）与稿件快照只追加不改写 |
| 课题包·部分导出（A08） | 研究面板「导出课题包（部分）」 | 研究记录 + 文献元数据清单 + manifest（包含/排除清单、分段 sha256）；导入校验和，篡改包拒绝；恢复报告按 contentHash/ID 匹配文献，缺原文明示不伪造完整 |
| 二次选题（A09） | 研究面板「二次选题」 | 选择既有成果（假设/结论/运行/对比表/方案/比较）为输入并固定快照摘要；未解问题分类登记（失败不被忽略）；候选方向须注明依据与验证动作，可回写为新假设或方案草稿（不重复创建）；记录研究决定（继续/收缩/转向/停止）。与初次选题页互不影响 |
| 投稿与修订（A10） | 研究面板「投稿与修订」 | 投稿轮次（目标、稿件关联、材料清单准备/已提交分列、三段时间）；审稿意见粘贴按空行拆解为草稿，逐条分类（解释/修改/补实验）与处置，处置可引用运行/结论/稿件；checklist 汇总待处理项；改投新建轮次不覆盖上一轮。平台不自动登录投稿网站或发送回复 |
| 导出 / 导入（B1.6） | 研究面板底部 | 导出 JSON 打包全部研究记录（含方案冻结版本与比较快照）；导入幂等，已存在记录跳过；可恢复到其他项目 |

## 推荐路径

选已有项目 → 阅读论文 → 划选保存证据 → 在对比表中比较文献 → 登记假设并关联证据 → 记录下一步。原有选题、研读、实验脚本和写作方式不受影响。

## 数据与存储

- 记录位于 `data/research/<projectId>/`：`profile.json`、`evidence/*.json`、`matrices/*.json`、`hypotheses/*.json`。
- 每条记录经统一存储登记（kind：`research-profile` / `research-evidence` / `research-matrix` / `research-hypothesis`），删除进回收站、可恢复；「资料」面板可见。
- 成果关联、证据来源都是**引用**：解除关联或删除记录不会移动、修改论文与知识资源。
- 导出包含 `schemaVersion`；导入保留原始 ID、时间戳与关联关系。

## 推荐路径（第二批）

现有实验脚本运行 → 导入结果（CSV/JSON 列映射）→ 保存比较快照（口径差异显式说明）→ 登记结论（区分探索性与正式判断）→ 引用比较作为结论依据。平台不接管原有训练环境。

## 推荐路径（第四批）

已有结论与失败实验 → 二次选题（输入快照 + 未解问题 + 候选方向）→ 回写新假设/方案草稿进入下一轮；稿件定稿后登记投稿轮次 → 收到意见粘贴拆解 → 逐条处置并关联补实验 → 归档或新建改投轮次。

## 已知限制

- 检索来源证据暂不支持从证据卡一键跳回检索结果的对应代次，仅展示来源元数据；论文来源可一键回原文。
- 单元格暂无「AI 建议候选」填写入口（字段与显示标记已预留）。
- 完整课题包含文献元数据清单与校验和，但仍不含 PDF 原文与外部文件，属于部分导出，不能当作完整备份；恢复时缺原文的论文保留引用 ID 并在报告中明示。
- 二次选题的补充检索（A09.3）复用现有「找论文」入口手动执行，暂未在二次选题区块内嵌检索；候选依据引用只支持项目内研究记录。
- 意见处置的引用添加当前版本通过保存时的 JSON 引用，面板内选择器待后续补充；投稿平台对接、自动回复与 Word 动态引用不在范围内。
- 引用标记以复制粘贴方式进入稿件，编辑器内嵌引用侧栏尚未实现；.bib 为 @misc 兜底格式，未按期刊/会议细分条目类型。
- 假设关联的证据被删除（回收站）时，假设记录保留但依据显示为原始 ID。
- 实验导入的产物登记为路径引用，未做受管副本；比较快照不随上游运行更新自动重算，需要新结果请新建比较。
