# 学术搜索与当前研究匹配

在检索面板选择当前项目，勾选「结合当前研究与 RAG」，填写主题或方法关键词后检索。研究问题、范围、阶段目标与约束来自该项目的「研究」档案；没有档案时使用项目文献和检索词作为有限的参考，并在面板说明来源。空项目不会借用整个文献库作为项目画像。

外部学术来源并行查找论文，聚合去重后结合项目研究档案与项目知识库已发布版本的原文证据给出匹配分、用途建议和理由。知识库召回复用现有混合检索，使用一次有预算限制的检索；向量服务不可用时回退到本地原文词法检索。没有已入库证据时显示缺口并保留外部搜索结果。

用途可同时属于多个类别：

| 用途 | 阅读目的 |
| --- | --- |
| 找创新点 | 比较问题、限制与潜在研究缺口，进一步核验差异 |
| 改模块 | 寻找可对齐和比较的方法、模块、实现或消融 |
| 选题必读 | 理解相关研究领域、问题背景、综述或基础工作 |
| 背景参考 | 补充相关术语、任务背景或实验解释 |

匹配与用途是阅读建议。面板列出摘要或标题依据、匹配到的项目证据、页码及版本；低置信建议需要阅读原文确认，不表示已经核验创新性或实验改进。

可按「当前研究匹配」排序，按用途筛选已返回的结果。加入待读会保存匹配快照；待读条目可手工选择用途，选择「自动建议」恢复建议。下载加入项目时用途和证据快照随论文保存，同一篇论文在不同项目中的用途独立。文献列表显示当前项目的用途。

## 搜索服务状态

每个来源独立返回成功、数量或错误原因。部分来源失败不丢弃其他来源结果；所有来源失败显示来源故障，区别于成功检索后没有命中。未选择任何来源会明确提示选源。系统 HTTP/HTTPS 代理或 `PIPAPER_HTTPS_PROXY` 支持固定学术来源的 CONNECT 域名解析，兼容 Clash fake-IP DNS。自定义站点和下载目标遇到 fake-IP 时，通过固定公网 DoH 解析并核验目标为公开地址；私网、畸形记录或无有效记录仍拒绝。显式配置的本地 HTTP 镜像可用，禁止跨来源重定向传递凭据。

OpenAlex 可复用已有选题配置中的 API 密钥或检索源凭据；Semantic Scholar 的匿名请求可能限流，可在检索源设置添加密钥。来源凭据由服务端保存，前端只返回掩码。

## 接口

- `GET /api/search?q=...&projectId=...&research=1&sort=research`：开启匹配；`research=0` 关闭。响应包含 `researchContext`、结果的 `researchMatch` 与各源 `sourceStatus`。
- `POST /api/search/toread`：保存元数据及可选 `researchMatch`、`purposeCategories`。
- `PATCH /api/search/toread/:id`：传入 `{"purposeCategories":["module"]}` 修改人工分类；空数组恢复自动建议。
- `POST /api/search/import`：可带上述分类字段；对应项目的快照存入论文 `literatureContexts`。

分类标识为 `innovation`、`module`、`topic`、`background`。查询外部论文或加入待读不会自动下载 PDF，也不会为整个文献库自动入库。
